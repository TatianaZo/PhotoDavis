# PhotoDavis — портфолио Димитрий Дэвис

Статический сайт: HTML, CSS, JavaScript, GSAP, Lenis.

## Публикация на GitHub Pages

1. Откройте [Settings → Pages](https://github.com/TatianaZo/PhotoDavis/settings/pages).
2. В **Build and deployment** → **Source** выберите **GitHub Actions**.
3. Подождите 1–2 минуты после push в `main` (вкладка **Actions**).
4. Сайт будет доступен по адресу: **https://tatianazo.github.io/PhotoDavis/**

## Локальный запуск

```bash
python -m http.server 8080
```

Откройте http://localhost:8080/
